CIPs realizados por operador

Quantidade de registros de CIP por operador no período e filtros selecionados (não é percentual de execução). Clique em uma barra para ver os registros do operador.

Avaliação dos CIPs

Os totais seguem os filtros acima. "Revisão necessária" é uma sinalização à parte: o registro mantém a última classificação (Conforme ou Contaminado), mas teve dados alterados depois dela e ainda não foi reavaliado. A classificação é sempre decisão do supervisor.

O período e os demais filtros do topo também valem para as filas. Os tempos usam os horários gravados no banco, no fuso da fábrica.

CIPs aguardando avaliação 0

Registros que ainda não receberam a primeira avaliação.

Revisão necessária 0

Já avaliados, mas com dados alterados depois da avaliação.
